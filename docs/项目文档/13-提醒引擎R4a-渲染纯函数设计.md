# 提醒引擎 R4a — 渲染纯函数设计（render.py）

> 上游：09 §F3（聚合是纯渲染分组）/ §F4（`send(student_id, channel, content)`）；契约源：`candidates.py` 的 `payload_vars` 形状。
> 范围：`payload_vars → content` 的 f-string 渲染，**纯函数先行**（与 R1 同套路：零 IO / 零调度 / 零推送，单测直调）。门序接线（R4b）不在本切片。

## 一、输入契约（由 R1 候选生成器定死，渲染层只消费）

| subject | `payload_vars` 形状 | 来源 |
|---|---|---|
| `library_due` | `{"items": [{"title": str, "barcode": str, "due_date": date}, ...]}`（≥1 项，**同束共享同一 due_date**——锚点日分组即 `due_date − days`，组内必同日） | `due_library_candidates` L207-225 |
| `course` | `{"course_name": str, "location": str, "teacher": str, "start": datetime, "is_changed": bool, "change_note": str}` | `due_course_candidates` L295-302 |

## 二、设计决策（定版）

### D1 API 形状

```python
def render_library_content(payload_vars: Mapping[str, Any], now: datetime) -> str
def render_course_content(payload_vars: Mapping[str, Any]) -> str
def render_candidate(candidate: Any, now: datetime) -> str   # 按 subject 分发入口
```

- **借阅渲染需要 `now`**（算"N天后到期"），课程渲染不需要（文案只有 HH:MM，不含"今天/明天"相对词——课程候选的扫描时刻与开课可能跨天，写相对词必错）。
- `now` 复用 `evaluator.CAMPUS_TZ` 同源常量换算本地日（天数 = `due_date − 校园本地今天`），禁止用服务器本地时。

### D2 文案模板（f-string，中文朴素口吻）

- 借阅单本：`【图书到期提醒】你有 1 本书3天后到期：《三体》（条码 01020304），到期日 2026年10月29日。请及时归还或续借。`
- 借阅聚合：`【图书到期提醒】你有 2 本书3天后到期：《三体》《活着》，到期日 2026年10月29日。请及时归还或续借。`（条码只在单本时展示——聚合后条码列是噪音）
- **天数词**：`0 → 今天`、`1 → 明天`、`N → N天后`（"到期"共用）。
- 课程普通：`【上课提醒】14:00 《数据结构》在 敬贤楼201 上课，主讲 王老师。`
- 课程调停课（**is_changed 高亮**）：文本通道无样式，高亮 = **固定标记前缀 + 变更说明追加**：
  `【调停课】《数据结构》课程安排有调整：14:00 敬贤楼201，主讲 王老师。变更说明：{change_note}。`（`change_note` 为空则省略说明句）

### D3 失败语义：显式抛 `ValueError`，绝不静默渲染

| 触发 | 行为 |
|---|---|
| `payload_vars` 缺键 / 形状不对 | `ValueError`（脏数据定位到渲染层，R6 不确定即转人工的时间版） |
| 借阅 `items` 为空 | `ValueError`（候选生成器保证 ≥1，出现即上游 bug） |
| `due_date − 今天 < 0`（已到期书进渲染） | `ValueError`（候选生成器已滤超期，出现即 P1 事故路径 09 K3，必须炸出来） |
| `now` 无时区 | `ValueError`（与 `_require_aware` 同语义） |
| 未知 subject（分发入口） | `ValueError` |

### D4 is_changed 契约源说明

任务引用"文档 10 §7.3 #5"，本仓库文档 10（R3a 实施设计）无此节——以 `candidates.py` L256 注释「`is_changed` 调停课变更进 payload_vars，渲染层必须高亮」为准，模板中的【调停课】标记即该要求的落法。若后续找到上游 §7.3 原文，差异处回改本设计。

### D5 与 F4 的衔接

`PushAdapter.send(student_id, channel, content)` 的 `content: str` 即本层输出——纯文本、单条消息、可逐字单测断言。渲染层不感知通道（企微/桩共用同一文案，09 §2.5 通道抽象）。
